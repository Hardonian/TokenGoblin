Find waste

Zombie agents

Agents that keep spending while their output gets rejected. Zero-acceptance workers with unpriced spend surface too — invisible cost is the worst cost.
Attribute

Cost by model & feature

Windowed cost per model and per feature, with ROI defined as cost per accepted output — so "expensive" and "productive" stop being the same conversation.
Scale

Analytics that can't hurt ingestion

Events persist to the source of truth first, then mirror best-effort. Analytics degrade to a clear error — they never fabricate numbers and never block a write.
